# Slock Store — E-commerce Platform

Slock Store is a smart-lock e-commerce platform with regional payments and a fast, reliable checkout experience.

![Slock Store](assets/hero.png)

## Highlights

- Complete e-commerce experience built from scratch
- Reusable design-system UI library
- Mada and Apple Pay with automated webhook reconciliation
- Push-notification flows that drive repeat purchases
- Firebase Crashlytics for release monitoring

## Tech stack

Flutter · Firebase · Crashlytics · Mada · Apple Pay

## My role

**Flutter Developer** — built the app, design system, payment integrations, and notification flows.
